# ぷよぷよ完全再現 (Puyo Puyo - Procedural Slime Simulator)

外部キャラクター画像等を使わず、HTML5 Canvasとプロシージャルグラフィックス、Web Audio APIを極限まで駆使して制作された**ぷよぷよ完全再現Webアプリケーション**です。

🎮 **[今すぐブラウザで遊ぶ (GitHub Pages)](https://yhfujita.github.io/puyo-puyo/)**

---

## 🌟 特徴・再現機能

1. **ぷよの透明感・スライム質感 (Procedural Slime Jelly)**
   - 内部から光が透き通る多重ラジアルグラデーションと底面の反射光（アンダーグロー）
   - ガラス・ゼリーのような艶やかなハイライト光沢
   - アイドル時に生きているかのように呼吸するプルプルとした伸縮アニメーション
   - 接地・落下時の弾性変形（Squash & Stretch）

2. **もっちり繋がるアニメーション (Metaball Bridges)**
   - 同色のぷよが隣り合うと、ベジェ曲線のくびれブリッジが滑らかに伸びて有機的に融合
   - 操作中の組ぷよも同色なら回転に合わせてリアルタイムにモチッとくっつきます

3. **豊かな表情・生き生きとした視線AI (Eye & Emotion AI)**
   - 白目・瞳（黒目）・ハイライト・まばたきアニメーション
   - **視線AI**: アイドル時にキョロキョロ見回り、仲間と繋がると嬉しそうに見つめ合います
   - **多彩な表情**:
     - 通常時: 周囲を見回す
     - 仲間と連結時: 三日月目でニッコリ（笑顔）
     - 4個以上で消える直前: 目を見開きぐるぐる目を回してブルブル震える（焦り顔）
     - 落下中: 落下先の下方向を真剣に見下ろす
     - 操作中: プレイヤーのキー入力方向（左・右・下）を注視

4. **4つ以上で消えるアニメーション (Pop & Burst FX)**
   - 4個以上繋がると白熱点滅＆高速振動の予兆アニメーションへ移行
   - ポンッ！と弾けて破裂し、スライムの飛沫ドロップ、衝撃波リング、キラキラ光子パーティクルが飛び散る爽快な演出

5. **重力でちぎれて落下する物理挙動 (Chigiri Free Fall)**
   - 段差や横向きで設置した際、先に地面についた側はその場でバウンド接地し、空中に残ったぷよは重力加速度で「ちぎれ落下」して着地バウンド

6. **本格連鎖システム＆プロシージャルサウンド**
   - 消去後、空中に残ったぷよが重力落下し、着地後に再連結を自動判定する再帰的連鎖ループ
   - Web Audio API による自作音源（連鎖数に応じて音階とハーモニーが上昇するアルペジオシンセ音）
   - ド派手な「X 連鎖！」のカットイン表示、ぷよ通公式スコア計算、全消し（ALL CLEAR）判定＆黄金ファンファーレ演出

## 🎮 操作方法

| 操作 | キーボード | タッチ（スマホ/画面UI） |
| :--- | :--- | :--- |
| **左右移動** | `←` / `→` または `A` / `D` (長押しリピート対応) | `◀` / `▶` ボタン |
| **高速落下** | `↓` または `S` (ソフトドロップ) | `▼` ボタン |
| **即時落下** | `Space` (ハードドロップ) | `⚡` ボタン |
| **右回転** | `↑` または `W` / `X` | `↷ X` ボタン |
| **左回転** | `Z` または `Ctrl` | `↶ Z` ボタン |
| **リセット** | 画面の `🔄 リセット` ボタン | 画面の `🔄 リセット` ボタン |
| **サウンド切り替え** | 画面の `🔊 音: ON` ボタン | 画面の `🔊 音: ON` ボタン |

スマートフォンやタブレットのブラウザからも快適に操作できます。
