# ぷよぷよ完全再現 - PRO (Puyo Puyo - Procedural Slime Simulator)

外部キャラクター画像等を使わず、HTML5 Canvas、プロシージャルグラフィックス、Web Audio API、SMF MIDI音源を極限まで駆使して制作された**本格ぷよぷよ対戦Webアプリケーション**です。

🎮 **[今すぐブラウザで遊ぶ (GitHub Pages)](https://yhfujita.github.io/puyo-puyo/)**

---

## 🌟 新機能＆ハイライト

1. **⏸ Escキーで一時停止（ポーズ機能）**
   - ゲーム中に `Escape` キーを押すか、画面上のポーズボタンをクリックで瞬時にポーズ / 再開。
   - ポーズモーダルから「ゲーム再開」「最初からやり直す」「タイトルに戻る」を選択可能。

2. **🏠 タイトル画面＆モードセレクト**
   - 迫力のネオンロゴ＆プルプル揺れるスライムUI。
   - **1P とことんモード**: 大連鎖の練習やスコアアタック。
   - **VS CPU 対戦モード**: コンピュータとの白熱した対戦バトル！

3. **⚔️ コンピュータ（CPU）対戦 ＆ おじゃまぷよ相殺システム**
   - **3段階のAI難易度**: かんたん (Easy) / ふつう (Normal) / ゲキムズ (Hard)。
   - **ぷよ通準拠のおじゃまぷよシステム**:
     - 連鎖を起こすと得点に応じて相手におじゃまぷよが送信。
     - **相殺（そうさい）**: 相手からおじゃまぷよが予告されている間に自分も連鎖を起こすと、その分おじゃまぷよを打ち消し＆余剰分を相手に跳ね返す！
     - 予告おじゃまぷよはターン終了時に上から岩のように落下。
     - 周囲の色ぷよが消える時に巻き込まれて消滅！
     - おじゃまぷよ専用のクリスタル質感とうるうる怯え目。

4. **🎵 MIDIファイル再生機能 ＆ ぷよぷよ風オリジナルMIDI BGM**
   - Web Audio API による自作 Standard MIDI File (.mid) パーサー ＆ シンセサイザー音源。
   - 軽快でハイテンポなぷよぷよライクのオリジナルチップチューンBGMを内蔵・ループ再生！
   - BGM / SE 個別ON・OFF機能。

5. **✨ ワイド大画面フィールド対応 (8列×14段)**
   - 通常の公式規格「クラシック (6列×12段)」に加え、ぷよをたっぷり置ける「ワイド大画面 (8列×14段)」モードを搭載！
   - 10連鎖〜15連鎖以上の超巨大連鎖を組める広大フィールドで爽快感MAX！

6. **💧 ぷよぷよの質感・演出の極致**
   - ゼリー・スライム特有の光の透過光・屈折影・艶やかなハイライト光沢。
   - 同色ぷよが上下左右でベジェ曲線を描いて有機的にもっちり一体化。
   - アイドル時にキョロキョロ見回り、仲間と繋がるとニッコリ笑顔、4つ消去直前は目を見開いてぐるぐる目を回す視線表情AI。
   - 横向き・段差接地時の「重力ちぎれ落下」と着地バウンド。
   - 全消し（ALL CLEAR）判定＆黄金ファンファーレ演出。

## 🎮 操作方法

| 操作 | キーボード | スマートフォン / 画面UI |
| :--- | :--- | :--- |
| **一時停止 / 再開** | `Escape (Esc)` | `⏸ ポーズ` ボタン |
| **左右移動** | `←` / `→` または `A` / `D` (長押しリピート対応) | `◀` / `▶` ボタン |
| **高速落下** | `↓` または `S` (ソフトドロップ) | `▼` ボタン |
| **即時落下** | `Space` (ハードドロップ) | `⚡` ボタン |
| **右回転** | `↑` または `W` / `X` | `↷ X` ボタン |
| **左回転** | `Z` または `Ctrl` | `↶ Z` ボタン |
| **BGM切替** | 画面の `🎵 BGM` ボタン | 画面の `🎵 BGM` ボタン |
| **効果音切替** | 画面の `🔊 SE` ボタン | 画面の `🔊 SE` ボタン |

PCだけでなくスマートフォンやタブレットのブラウザからも快適に操作いただけます。

## 🛠 技術スタック
- **Frontend**: Vanilla JavaScript (ES6+), HTML5 Canvas 2D, CSS3
- **BGM & Sound**: Web Audio API (FM/Subtractive Synthesizer), Standard MIDI File Parser (.mid)
- **AI**: Heuristic Evaluator (CPU VS mode)
- **Deployment**: GitHub Pages, GitHub Actions
